# 远端操作

连上主机后再排查。已配置两台及以上时，每个面向远端的 `ssh_*` 调用都要带 `host`。

- 先用 `ssh_ls`、`ssh_read` 和只读的 `ssh_exec`。
- 用户拒绝后不要改写命令再试——拒绝就是拒绝，换一种写法绕过去属于违背用户意图。
- 需要 root 用 `ssh_sudo`，不要把密码写进命令，也不要让用户把密码贴进对话。
- 传输用 `ssh_put` / `ssh_get`。**不接受目录**：要传目录先在本地打成压缩包再传。
- 首次连接遇到未知主机密钥会失败并给出 `SHA256:...` 指纹，让用户用 `ssh-keygen -lf` 核对后再确认；不要用 `acceptNewHostKey` 跳过这一步。
- 命令超时/断开后远端进程会被看门狗清掉；若结果里出现「没有 job control 也没有 setsid」的警告，说明远端只能靠关通道清理，长任务请自己套 `timeout`。
- 输出超 50KB 或 2000 行会截断，全文路径在结果末尾，需要细节就 `ssh_read` 那个文件或缩小命令范围。
- 主机是 FTP/FTPS 时只有传文件能力，`ssh_exec`/`ssh_read` 会明确拒绝，改用 `ssh_get` 拉回本地读。
